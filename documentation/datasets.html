1. Origin

All datasets are ENCODE eCLIP experiments (two IP replicates + a size-matched input control, aligned to GRCh38.primary_assembly). Each dataset lives under data/<RBP>_<cell>/ in a fixed layout:

  • bam/{ip_rep1_v1,ip_rep2_v1,smi_v1}/*.bam — the two IP replicates and input, plus .bai indexes
  • top_regions/regions.bed6, top_crosslink_sites/crosslinks.bed6, top_genes/list.txt, biotypes_genetypes/*.tsv — ENCODE benchmark references for scoring

The preliminary batch (5 datasets) was already present. In July 2026 three Google-Drive folders were added (37.6 GiB, downloaded to data/incoming_gdrive/ and extracted). After de-duplication these contributed 20 new datasets; one Drive folder was an exact re-package of the preliminary batch and several files were cross-folder duplicates (not re-ingested).

4. What they add

  • Scale: the benchmark grows from 5 to 25 datasets (5×) — more statistical weight for comparing optimizers (LLM vs Optuna) and motif-aware scoring.
  • Diversity: a new class of RBP (splicing factors) that stresses the pipeline beyond crisp-motif proteins.
  • Paired cell lines (K562 + HepG2 for most RBPs) enable cross-cell-line reproducibility analysis.
  • PUM2_K562 is a positive control: same motif family as PUM1, so existing priors transfer directly.
Caveat — motif priors. For the positional binders (U2AF1/U2AF2/SF3B1/SF3B4/RBM22) the "target motif" is a weak/degenerate proxy. Motif-aware scoring should be down-weighted or replaced by a positional prior for these, or scores will mislead. Also confirm each dataset's shipped benchmark files were generated consistently with the preliminary batch before treating scores as directly comparable.

5. How to run

Datasets are registered in pipeline/datasets.py; per-dataset configs live in config/datasets/*.yaml. Preliminary (chr21-restricted) optimization for all 20:

uv run python scripts/batch_runner.py --manifest config/new_batch_runs.yaml --parallel 4

Results land in results/batch/<run_id>/, summarized in results/batch/_summary.tsv.

Recommendation. Optimize on restricted regions (chr21, minutes per iteration) to search PureCLIP parameters, then run a single full-genome confirmation per dataset (~3.5 h each). This keeps the search cheap and pays the full-genome cost only ~20 times. Prioritize PUM2 (control) and the splicing factors (highest analytical value), but fix the per-RBP motif priors first so scoring stays meaningful. Budget ≈ 3–4 machine-days for the full new batch end-to-end.
