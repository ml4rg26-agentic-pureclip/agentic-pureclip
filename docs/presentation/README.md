# Presentation — results data pipeline

The deck (`index.html`) is static, but every **number in the four results tables**
comes from a single data store you can regenerate. SVG charts are still manual.

## Files
| File | What |
|---|---|
| `index.html`, `styles.css`, `script.js` | the slide deck (open `index.html` in a browser) |
| `final_results.json` | **canonical results store** — every run's per-iteration scores + params + LLM reasoning, plus the computed slide aggregates and their provenance |
| `build_results.py` | regenerates `final_results.json` from `data/iterations.jsonl` and injects the 4 tables into `index.html` |
| `PRESENTATION_FACTS.md` | fact-check of every claim vs. the code + the meeting-feedback TODO |
| `RESULTS_PLAN.md` | the repo changes + 34-run batch plan (for the code colleague) |

## Update workflow (results → slides)
1. Put the latest `iterations.jsonl` in the repo's `data/` folder (gitignored).
   Optionally point at a directory tree of per-run `decisions.jsonl` for LLM reasoning.
2. Run:
   ```bash
   python docs/presentation/build_results.py                 # json + inject tables
   python docs/presentation/build_results.py --json-only     # just rewrite the json
   python docs/presentation/build_results.py --decisions-dir results/overnight
   ```
3. Reload `index.html`.

**Real results override the illustrative placeholders cell-by-cell**; any dataset
not yet run keeps its placeholder, so the deck is always whole. `final_results.json`
→ `source` marks each aggregate cell as `real` or `placeholder`, and `meta`
reports how many are real.

## What's automated vs. manual
- **Auto (from data):** the 4 result tables (between `<!-- AUTO:key -->` markers)
  **and** the trajectory charts — convergence, per-factor, ablation — rendered with
  matplotlib to `figures/*.svg` and embedded as `<img>`. Both are rewritten on every
  `build_results.py` run; real results where available, illustrative fallbacks otherwise.
- **Manual (still placeholders):** the `ILLUSTRATIVE` badges, speaker notes, and the
  image placeholders the team supplies — eCLIP figure & BAM/site examples (slide 2),
  the UI screenshot (slide 5), and the RNA-RBP concept image (slide 8).

## Figures
`figures/`: `conv_optuna.svg`, `conv_llm.svg`, `factors_optuna.svg`, `factors_llm.svg`,
`ablation_with.svg`, `ablation_without.svg`. Styled to match the deck; regenerated by
`build_results.py` (skip with `--no-charts`).

## `final_results.json` schema
```
meta         provenance, counts (e.g. headtohead_cells_real)
aggregates   { headtohead, factors, ablation, crosscell }  — the values shown on slides
source       same shape as aggregates; each leaf = "real" | "placeholder"
placeholders the illustrative fallbacks
runs         "<DATASET>_<arm>"  (arm ∈ optuna | llm | llm_noprior) →
               best_composite, best {reproducibility, motif, recall, iteration},
               baseline_composite (iteration 0), n_iterations,
               iterations: [ { iteration, composite, reproducibility, motif, recall,
                               n_binding_sites, params, reasoning } ]
```

The 34-run design (14 datasets × arms) is encoded at the top of `build_results.py`
(`HH_ORDER`, `TIER`, `ABLATION`, `CC_ORDER`).
