\section{Conclusion}
\label{conclusion}

This work presents an automated framework for optimizing PureCLIP and
post-processing parameters on eCLIP data. The LLM and TPE strategies share the
same bounded search space, workflow, composite objective, and durable result
records. The framework thereby supports auditable comparisons while protecting
against degenerate few-site solutions.

Across 12 completed chromosome-21 dataset--cell-line pairs, automated search
usually improved the shared default. TPE produced the higher observed best score
in ten pairs. Because TPE usually
received roughly twice as many evaluations, this is a result of the implemented
protocol rather than a fair ranking of optimizer efficiency. Biological context
gave the prior only a slight mean edge of 0.004, while the median difference was
$-0.002$ and the direction varied by dataset. The predicted monotonic relationship
between motif difficulty and prior benefit was not observed. The main outcome is therefore a
reproducible test bed and a subset-level empirical baseline.
