\section{Discussion, Limitations \& Future Work}
\label{discussion}


\begin{itemize}
  \item \textbf{Note: interpretations are expectations, not results yet.} The full LLM-vs-Optuna head-to-head (and the motif-difficulty side-experiment) are still running, so the points below are framed as what we expect the results to show, to be confirmed once the numbers land.
  \item \textbf{Interpretation via motif difficulty (hypothesis).} Proteins differ in how sequence-defined their binding is, a spectrum from \emph{crisp} k-mer motifs (RBFOX2 \texttt{UGCAUG}, PUM \texttt{UGUANAUA}), through \emph{degenerate} ones (HNRNPK C-rich, SRSF1 GA-rich), to \emph{positional} / non-k-mer binders (U2AF2 polypyrimidine tract, SF3B1/4 branch point). The motif term is a strong signal for the first group and a weak one for the last. We therefore expect the LLM's biological prior to help most where that signal is weakest and Optuna is searching blind, i.e.\ the LLM's margin over Optuna should widen crisp $\rightarrow$ degenerate $\rightarrow$ positional. A focused side-experiment (\texttt{config/insight\_llm\_vs\_optuna.yaml}: PUM2 / SRSF1 / HNRNPK / U2AF2 / SF3B4, K562, both optimizers) tests this; the batch is still running. Note the difficulty label is our manual annotation, not a quantity the pipeline computes, and if the margin does \emph{not} widen, that is itself a finding: the prior buys little on hard proteins.
  \item \textbf{The single fixed objective does not fit every dataset.} Our composite is one hard-coded formula applied to all datasets, which has two distinct consequences:
    \begin{itemize}
      \item \emph{Equal-replicate assumption (supervisor's point).} The reproducibility term (weight $0.5$) treats the two lab replicates as equally good. If we know one replicate is of much lower quality, its agreement score is misleading and the fixed weights cannot compensate. We keep the current weighting for time; quality-aware or learned weighting is the natural fix.
      \item \emph{Weak motif proxy for positional binders.} For U2AF/SF3B/RBM22 the motif term (weight $0.25$) is only a proxy, because binding is defined by splice-site position, not a k-mer. Composite scores for these should be read with care; a positional prior is the natural fix (identified, not implemented).
    \end{itemize}
  \item \textbf{Infrastructure as a contribution.} The shared-objective dashboard and manifest-driven runners make the study reproducible and the LLM-vs-Optuna comparison auditable per iteration.
  \item Limitations already outlined below: chr21-only, small search space, single LLM (no prompt ablation), budget asymmetry, mononucleotide-shuffle background, ENCODE reference is pipeline output not gold standard.
  \item \textbf{Future work.} The new data enables a paired cross-cell-line reproducibility analysis (K562 vs.\ HepG2), which we have not yet run. To pin down where any LLM advantage comes from, an iso-budget re-run (equal trial counts) and a prior-ablation of the LLM (removing the biological priors and the delta table) are the natural next steps.
\end{itemize}
