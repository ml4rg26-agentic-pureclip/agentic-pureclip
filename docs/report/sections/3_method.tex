\section{Methods}
\label{method}

\subsection{Datasets and workflow}

The repository contains a table-driven registry of 26 ENCODE eCLIP
datasets~\parencite{encode2012,vannostrand2020} covering 15 RBPs in K562 and HepG2
cells. Each entry specifies two deduplicated IP BAM files, an SMInput BAM file, a
GRCh38 reference, benchmark regions, and RBP-specific motif information. The
experiments analyzed in this report use PUM2, HNRNPK, U2AF2, QKI, and PUM1 in K562
cells. PureCLIP was restricted to chromosome~21 to make iterative evaluation
tractable. Reference regions were restricted to the same chromosome before recall
was calculated.

Both optimizers call the same \texttt{evaluate\_config()} entry point
(Figure~\ref{fig:pipeline}). The Snakemake workflow~\parencite{molder2021} merges
the IP replicates, runs PureCLIP\footnote{PureCLIP~2.0.4, the \texttt{pureclip2}
fork (\texttt{github.com/johan-stph/pureclip}).} on the merged BAM and separately
on each replicate, converts raw calls into standardized footprints, and calculates
the evaluation metrics. Each trial writes its parameters and scores to a
self-contained \texttt{score\_report.json} file.

\subsection{Composite objective}

For a call set with $n$ sites, the objective was
\begin{equation}
S = \left(0.50R_\mathrm{rep}+0.25R_\mathrm{motif}+0.25R_\mathrm{ref}\right)
\min\!\left(1,\frac{n}{10}\right),
\label{eq:composite}
\end{equation}
where $R_\mathrm{rep}$ is chance-corrected replicate agreement,
$R_\mathrm{motif}$ is the selected PWM hit rate, and $R_\mathrm{ref}$ is recall
of chromosome-21 reference regions. In practical terms, the components answer
three simple questions:

\begin{center}
\small
\begin{tabularx}{\linewidth}{@{}l>{\raggedright\arraybackslash}X@{}}
\toprule
Component & Intuitive calculation and interpretation \\
\midrule
Reproducibility & \textbf{Sites supported by both IP replicates $/$ all final
sites}, corrected for overlaps expected by chance. High values indicate that the
replicates independently support the same calls. \\
Motif support & \textbf{Sites containing the selected RBP motif $/$ all final
sites}. High values indicate that many calls match the protein's known sequence
preference. \\
Reference recall & \textbf{ENCODE reference regions overlapped $/$ all
chromosome-21 reference regions}. High values indicate that few known strong
regions were missed. \\
Yield guard & \textbf{Number of final sites $/$ 10}, capped at 1. This penalizes
only call sets with fewer than ten sites. \\
\bottomrule
\end{tabularx}
\end{center}

The following definitions specify the implementation. Let $C$ denote the final call set and
$P_1,P_2$ the regions called independently in the two IP replicates. Raw
agreement is the fraction of final sites supported by both replicates,
\begin{equation}
A_\mathrm{obs}=\frac{|\{c\in C:c\cap P_1\neq\varnothing
\ \land\ c\cap P_2\neq\varnothing\}|}{|C|}.
\end{equation}
The same fraction is calculated for three chromosome-preserving random
relocations of $C$, and their mean is $A_\mathrm{exp}$. Reproducibility is then
\begin{equation}
R_\mathrm{rep}=\max\!\left(0,\min\!\left(1,
\frac{A_\mathrm{obs}-A_\mathrm{exp}}{1-A_\mathrm{exp}}\right)\right).
\end{equation}
This uses the chance-correction form introduced for Cohen's kappa
\parencite{cohen1960}, but estimates expected overlap by genomic shuffling rather
than from rater marginals; the score is set to zero if $A_\mathrm{exp}=1$.
Interval intersections and shuffling are implemented
with BEDTools~\parencite{quinlan2010}.

For a PWM $m$ of length $L$, a sequence starting at offset $k$ receives the
standard log-odds score~\parencite{stormo1982}
\begin{equation}
q_m(k)=\sum_{i=1}^{L}\log_2\!\frac{\tilde p_{m,i}(x_{k+i-1})}{0.25},
\qquad
\tilde p_{m,i}(b)=\frac{p_{m,i}(b)+0.01}{1+4(0.01)}.
\end{equation}
For the minimum and maximum attainable PWM scores $q_m^-$ and $q_m^+$, the hit
threshold and site-level hit fraction are
\begin{equation}
\tau_m=q_m^-+0.8(q_m^+-q_m^-),\qquad
H_m=\frac{1}{|C|}\sum_{c\in C}
\mathbf{1}\!\left[\max_{k\in W_c}q_m(k)\geq\tau_m\right],
\end{equation}
where $W_c$ is the $\pm15$-nt window around site $c$. At scoring time, the motif
loader enumerates all five installed resources named in Section~\ref{theory}
and evaluates every PWM available for the target RBP and cell line. Resource
coverage is protein-dependent: HNRNPK has candidate motifs in all five resources,
whereas PUM2 and U2AF2 have candidates in mCrossBase, ATtRACT, and RBPmap. The
pipeline selects
$m^*=\arg\max_m H_m/H_m^\mathrm{shuffle}$, and sets
$R_\mathrm{motif}=H_{m^*}$. The enrichment ratio is reported but is not used in
Equation~\ref{eq:composite}.

Finally, for the chromosome-21 ENCODE reference set $G$,
\begin{equation}
R_\mathrm{ref}=\frac{|\{g\in G:\exists c\in C,\ g\cap c\neq\varnothing\}|}{|G|}.
\end{equation}
Thus, each reference interval is counted at most once, irrespective of how many
calls overlap it. All three components are bounded by zero and one. The final
factor in Equation~\ref{eq:composite} penalizes call sets with fewer than ten
sites. Both the weights and this yield penalty are project-specific design
choices. When a component is unavailable, the implementation renormalizes the
weights over the remaining components; all records used here contained all
three.

\subsection{Experimental conditions}

The principal experiment contains three arms for PUM2, HNRNPK, and U2AF2. The
\emph{LLM-with-prior} arm used DeepSeek \texttt{deepseek-chat} at low
temperature\footnote{Sampling temperature $0.2$ via the DeepSeek API
(\texttt{api.deepseek.com/v1}).}
\parencite{deepseek2024} and received the RBP identity, known motifs, an expected
footprint, the parameter
bounds, the current configuration, and the decomposed score trajectory. The
\emph{LLM-without-prior} arm received the same bounds, metrics, and trajectory,
but not the RBP identity or biological context. Thus, the ablation isolates the
information supplied in the biological prior; it does not remove numerical
feedback. Proposed JSON changes were validated against the search bounds and
retried after invalid responses. The \emph{TPE} arm used Optuna with seed 42 and
observed the scalar composite score.

All arms had a nominal cap of 16 evaluations and a stagnation threshold of 0.01
for four successive evaluations. For the LLM, counting began immediately. For
TPE, it began after the ten startup trials used by the sampler. Consequently,
the rule did not produce equal evaluation counts: completed LLM runs used five
to nine evaluations, whereas completed TPE runs used 14 to 16. The U2AF2 TPE run
was terminated by the batch time limit after two evaluations. QKI and PUM1 were
earlier pilot experiments under the same objective; the PUM1 TPE run also ended
at the batch time limit. All analyses are descriptive because each arm was run
once and no estimate of between-run variability is available.
