Enhanced crosslinking and immunoprecipitation (eCLIP) maps RNA-binding protein
(RBP) contacts transcriptome-wide, but converting aligned reads into binding
sites requires parameterised peak calling. We developed an automated framework
that optimizes seven PureCLIP and post-processing parameters against a composite
of replicate reproducibility, motif support, and reference-region recall. A
large language model (LLM) agent and a Tree-structured Parzen Estimator (TPE)
use the same pipeline, parameter bounds, and objective; a yield penalty excludes
degenerate solutions containing fewer than ten sites. We evaluated the framework
on chromosome~21 using three K562 datasets in a three-arm experiment (LLM with
biological priors, LLM without priors, and TPE) and two supplementary pilot
datasets. Optimization gains were dataset-dependent. On HNRNPK, the prior-equipped
LLM improved the default composite score from 0.242 to 0.329, whereas the
no-prior arm did not improve. The prior reduced performance on PUM2 and U2AF2.
TPE achieved the highest observed score on the three main datasets, but unequal
numbers of evaluations and an incomplete U2AF2 run prevent a controlled ranking
of optimizers. These results establish a reproducible evaluation framework and
provide preliminary evidence that biological context can alter LLM search
behavior; replicated, equal-budget experiments are required to determine when
that context improves peak calling.
