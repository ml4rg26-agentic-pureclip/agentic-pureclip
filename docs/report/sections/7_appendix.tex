\subsection{Reproducible artifacts}

The complete dataset registry is implemented in
\path{src/agentic_pureclip/pipeline/datasets.py}. Each trial stores its
configuration and decomposed measurements in \texttt{score\_report.json}; the
batch runner aggregates these records in
\path{results/overnight/iterations.jsonl}. A committed snapshot at
\path{scripts/analysis/iterations_snapshot.jsonl} reproduces the reported
figures with \path{scripts/analysis/report_figures.py}. The snapshot preserves
the append-only runner history; the figure script keeps the newest record for
retried job iterations. The HNRNPK decision trace discussed in
Section~\ref{results} was verified against the corresponding runner log.
